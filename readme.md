# IsingLHCE

A mean-field Ising model for rapidly predicting the solvation structure of Li+ in localized high concentration electrolytes (LHCEs). The model takes molecular properties of the solvent, diluent, and salt (DN, AN, concentration, volume) as input and predicts average solvent, diluent, and anion coordination numbers of Li+. Built with JAX for end-to-end differentiability and efficient parameterization from MD or experimental solvation structure data.
